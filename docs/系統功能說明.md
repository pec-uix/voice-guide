# 語音導覽系統功能說明

## 這個系統是什麼

語音導覽系統是一套專為展覽設計的數位導覽工具，讓參觀者**掃 QR Code 就能用手機聆聽作品介紹**，不需要下載任何 App。

展覽方透過後台網頁管理所有內容，不需要寫程式或操作資料庫，自己就能上架展覽、上傳音檔、查看數據。

---

## 參觀者怎麼用

參觀者不需要帳號，掃 QR Code 直接開啟，支援所有手機瀏覽器。

**掃展覽入口 QR Code**
- 看到該展覽所有作品的清單（標題＋圖片）
- 點進去進入個別作品頁
- 頁面上有展覽共用的評價連結

**掃作品旁 QR Code**
- 直接進入作品介紹頁
- 點播放按鈕聆聽語音導覽
- 逐字稿同步反白：播到哪段，畫面就標示哪段文字
- 右上角可切換語言（中文／英文），只有文字切換，音檔固定播中文
- 頁面下方有購買連結（點擊後開新分頁，不會離開導覽頁）

---

## 展覽方後台功能

用 Google 帳號登入後台，所有操作都在網頁上完成。

### 展覽管理
- 新增、編輯、刪除展覽
- 設定展覽名稱、簡介、評價連結
- 產生展覽入口 QR Code
- 貼上展覽網址一鍵匯入展覽＋全部作品（支援 uniart 等網站）

### 作品管理
- 新增、編輯、刪除作品
- 上傳作品圖片與音檔
- 填寫作品標題、藝術家、年份、介紹文字
- 管理逐字稿分段（設定每段的開始／結束秒數）
- 設定購買連結
- 產生作品 QR Code
- 貼上作品頁網址自動填入基本資料

### 多語言內容
- 儲存中文內容後，英文版本自動由 AI 翻譯產生草稿
- 後台標示「待校對」，確認文字正確後才標記完稿
- 可手動修改任何語言的翻譯內容

### 數據儀表板
- 查看每件作品的掃描次數、播放次數
- 購買連結點擊數、評價連結點擊數
- 了解哪些作品最受參觀者關注

## 自動化與輔助功能

| 功能 | 說明 | 使用時機 |
|---|---|---|
| 網址批次匯入 | 貼上展覽頁網址，自動解析展覽資料與全部作品 | 一鍵建立整個展覽與所有作品 |
| AI 自動翻譯 | 儲存中文內容後，自動產生英文草稿 | 每次新增或修改中文內容時自動觸發 |
| AI 自動轉錄 | 上傳音檔後，自動辨識逐字稿並附上時間戳記 | 沒有現成逐字稿時使用 |
| 語音合成 | 輸入文字，自動生成語音音檔 | 沒有錄製好的音檔時使用 |

---

## 技術架構

整套系統部署在 Cloudflare，費用目前為 $0／月，所有服務均允許商業使用。

| 角色 | 服務 |
|---|---|
| 網站前後端 | Next.js，部署於 Cloudflare Pages |
| 資料庫 | Neon（Serverless Postgres） |
| 音檔儲存 | Cloudinary |
| 自動翻譯 | Gemini API（Google AI Studio） |
| 後台登入 | Google 帳號登入（NextAuth.js） |
| 自動轉錄 | Groq Whisper API（選用） |
